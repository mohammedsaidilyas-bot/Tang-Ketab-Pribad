# Folder Kitab PDF Publik (Permanent Repository Assets)

Folder ini digunakan untuk menyimpan berkas PDF Kitab Turats secara permanen di dalam repository GitHub dan project aplikasi.

## Cara Kerja:
1. Simpan berkas PDF Kitab ke dalam folder ini (`public/kitabs/`).
2. Contoh nama file:
   - `0084-nihayatuz-zain.pdf`
   - `safinatun-najah.pdf`
   - `fathul-muin.pdf`
3. Berkas PDF yang diletakkan di folder ini akan otomatis ter-commit ke GitHub dan langsung dapat diakses/dibaca oleh seluruh pengguna aplikasi tanpa perlu mengunggah ulang.
